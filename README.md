## Publishing

GitHub Pages serves the `main` branch from the repository root. No build step, external fonts, JavaScript, analytics, or package installation is required. Publish only the files in this repository. Never add credentials, customer data, invoices, signatures, or private implementation files.

## Review before adoption

Confirm the legal operator/data-controller details, finalize retention and deletion arrangements, confirm service-provider and development-tool access practices, and verify the stated production controls. Adopt an effective date and remove the draft notices only after the text accurately describes approved operational practices. Do not claim these drafts have received a legal or security certification.

This repository hosts public documentation only. It does not host OAuth callbacks or process customer records. Linking these pages does not replace the separate connection/security/invoice implementation and testing work.
